# Snake

Move the snake and eat the food without hitting the walls or yourself.

## Controls

- Arrow keys or `W` / `A` / `S` / `D`: turn
- `G`: toggle the grid
- `Space`: restart after game over
- `Escape`: leave the game

## Run

Start the game in Compy with:

```lua
run("snake")
```
